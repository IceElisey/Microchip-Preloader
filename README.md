# Проект "Анимация микрочипа"

## Описание проекта 
Данный проект создан для того, чтобы во время загрузки чего-либо было не скучно смотреть.

## Цели проекта
- Скрасить время ожидания;
- Дать пользователям понять, что идет процесс загрузки.

## Используемые технологии
- HTML для верстки;
- CSS для настройки стилей.

## Установка 
Загрузите репозиторий. Для этого скачайте проект, а затем разархивируйте его.

## Использование
Чтобы увидеть результат кода, откройте папку с проектом, дважды нажмите на файл index.html. Результат появится в браузере.
